ACONSU design system

Tokens, components and key screens for the website and the app. Everything on this page is drawn with the website's own stylesheet; colour ratios are measured live in your browser, in your current light or dark setting.

Colour

Every text colour is shown on the background it is used on, with its measured contrast. AA needs 4.5:1 for text.

Status colours

Colour never carries meaning alone: each status also has a word.

Type

Source Serif 4 for headings, Source Sans 3 for everything else. Both are served from the site, so no request goes to Google.

Controls

Buttons

44px tall, 6px radius, never a pill. Press scales to 0.97 in 120ms. Hover only changes colour, and only where a mouse exists.

Fields

The label is always above the field, never inside it. An error uses words, a heavier border and a red that passes contrast, and focus moves to the field.

Feedback

Error message: says what is wrong and how to fix it.

Success message: says what happened.

Loading

A grey block where content is still arriving, so the page does not jump. It pulses opacity only, and stays still for people who asked for less motion.

Motion

Opacity and transform only. 150ms for state changes, up to 360ms for things arriving, always ease-out, played once. Nothing moves on a loop. With reduced motion on, arrivals become a 150ms fade.
