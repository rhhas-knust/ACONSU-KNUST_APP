# The emblem and icons before the navy recolour

`scripts/recolor-brand.js` recoloured the crest and the icons from purple to navy. The originals of the logo, the web
and Android icons and the favicons are here, in the same folder layout as the repository: copy one back over its
file to undo it.

The Android launch splash pictures (`android/app/src/main/res/drawable*/splash.png`) are not copied here because they
are large; their purple originals are in git history, at commit `f5ddc45`:

    git checkout f5ddc45 -- android/app/src/main/res

`public/video/how-to-aconsu.mp4` and its poster were never recoloured.
